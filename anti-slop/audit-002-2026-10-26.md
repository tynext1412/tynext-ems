## Temuan

### HIGH (Hard Gate)

18. **R-38 / C-5, angka harian plant OFFLINE tidak konsisten.** PLT-010 offline (data terakhir 40 menit
    lalu, PV 0 kW) tetapi Operating Data hari ini menampilkan Daily Yield 1.455,84 kWh dari mock. Mock
    operating data belum memperhitungkan status/ketersediaan device. Perbaiki generator mock, atau tandai
    tile sebagai data dummy (kaitannya dengan audit 001 #4).
19. **R-24 / R-26, dua menu stub.** SCADA dan O&M schedule ada di sidebar tanpa isi. Sudah diberi label
    jelas "belum dirancang" (jadi bukan kontrol mati), tetapi tetap menu tanpa tujuan nyata. Pilih:
    biarkan dengan label sampai spesifikasi ada, atau sembunyikan dari sidebar sampai dibangun.
20. **R-03, diagram aliran energi terlalu kecil di ponsel.** SVG diskalakan ke lebar 414 px sehingga
    label node (10–11 px di viewBox) jadi ±7 px. Perlu layout vertikal khusus layar sempit atau ukuran
    font yang tidak ikut diskalakan.

### MEDIUM (Purpose-Gate)

21. **R-19, animasi garis putus-putus berjalan terus selama ada daya.** Tujuan tertulis: menunjukkan arah
    aliran daya real-time (konvensi diagram EMS/SCADA); mati saat `prefers-reduced-motion`. Tetap sebuah
    loop tanpa pemicu pengguna, jadi tercatat untuk diputuskan: pertahankan (alasan domain) atau ganti
    panah statis.
22. **R-04, ikon Lucide bertambah** (MapPin, ChevronRight, ArrowLeft, glyph cuaca di prakiraan). Semua
    fungsional/relevan; tampilan library default tetap (lihat audit 001 #10).
23. **R-01 / Part 3, aksen tembaga** dipakai untuk menu aktif, node aktif di diagram, badge jumlah alarm
    (warn), link Info, "Kembali ke Overview". Masih sebaran yang sama dengan audit 001 #9; putuskan bersama.
24. **R-06, bahasa label campur.** Label data memakai istilah spesifikasi (Daily Yield, Plant Information,
    Today) sedangkan teks bantu Indonesia (Aliran energi saat ini, Terhubung, Riwayat). Konsisten dengan
    dashboard, tetapi belum ada keputusan bahasa UI tertulis. Tetapkan di `DESIGN.md` (audit 001 #5).

### LOW (Quality Locks)

25. **R-27, kartu Weather tidak punya state "data lama".** Prakiraan dari mock selalu segar; saat adapter
    HTTP dipakai, tampilkan waktu ambil terakhir seperti header.
26. **R-20, kartu Plant Information memakai kotak "Foto plant belum tersedia".** Jujur, tetapi area kosong
    besar; pertimbangkan menghilangkan slot foto sampai aset ada, atau mengganti dengan peta mini lokasi
    (data sudah ada).
27. **R-14, tile Operating Data dan tile Daily di panel aliran identik bentuknya.** Daily Yield muncul dua
    kali di Overview (panel aliran dan Operating Data mode Day). Hilangkan salah satu, atau jadikan tile di
    panel aliran sebagai ringkasan "hari ini" saja dan Operating Data mulai dari Month.
28. **Format waktu `id-ID` memakai titik untuk jam ("12.12.13").** Benar untuk locale Indonesia, tetapi
    berbeda dari contoh desain ("15:09:49"). Putuskan pemisah jam.
